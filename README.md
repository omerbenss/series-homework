# Question 2
{ ...show } הוא עותק של השכבה העליונה בלבד, ולכן `seasons` בעותק מצביע לאותו מערך כמו במקור. בגלל זה ה-`push` שינה את הערך במערך המקורי דרך העותק, והעותק לא הגן על כלום. בתיקון יצרתי סדרה חדשה, מערך עונות חדש, עונה חדשה ומערך פרקים חדש. כל שאר העונות נשארו אותו אובייקט, בלי שינוי.
